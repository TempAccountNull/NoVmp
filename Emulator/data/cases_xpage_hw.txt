# U2043 (P37, the sample's #GP): lazy flags of an instruction whose NEXT instruction crosses into the next page.
# Hardware cases (the i5-13600K vs Unicorn): emu-alltest --cases Emulator\data\cases_xpage_hw.txt
# Our own bytes only (never sample bytes): each snippet writes a short routine at CODE + 0FF7H (30000FF7H, inside the
# harness's executable CODE region on both engines; the rest of CODE is HLT) and calls it. In the routine the instruction

# SDM 334569-093 Vol2D p. 6-41 XOR "Flags Affected": OF and CF cleared, SF / ZF / PF from the result, AF undefined;
# 253666-093 Vol2A p. 3-10 ADC "Operation": DEST := DEST + SRC + CF; MOV / RET: no flags affected.
#
