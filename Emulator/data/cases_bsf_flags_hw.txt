# SDM 325383-092 Vol2A BSF / BSR "Flags Affected": ZF = 1 for a zero source, else 0; "The PF flag
# is set to 1 if the number of bits set in the source operand is even; otherwise, it is cleared.

# "undefined".) The emulator implements SDM 092. The i5-13600K agrees in ZF, CF, OF, SF, AF (0
# whatever the input flags; 0x202 / 0xAD7 inputs below) but gives PF = the parity of the low byte
# of the RESULT (the bit index): lines where the two PF rules differ carry
# "# known deviation: BSF/BSR PF" (docs/quirks.md).
