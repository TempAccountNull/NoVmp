# with the TSC RDTSC returns (IA32_TSC_ADJUST included); while TSC < deadline = min(EDX:EAX, TSC +
# (IA32_UMWAIT_CONTROL[31:2] << 2), 0 = no maximum) the TSC jumps to the end of the wait (no real sleep): the deadline
# or, earlier, TSC + W, the environment wake period (U1622, user decision 2026-10-18 "Wake after ~1 ms": W = 2^21
# ticks, CF = 0); UMWAIT only while a UMONITOR range is armed (U1621), and a UMWAIT that ended disarms the range
# (U1852, bare host H22 item 5); CF = 1 only when the OS limit ends the wait;
